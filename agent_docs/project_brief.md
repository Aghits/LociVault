# Project Brief

- **Product vision:** Build memory palaces in minutes, not hours.
- **Target Audience:** Medical students memorizing large volumes of complex terminology.

## Conventions
- **Naming:** camelCase for variables, functions, and standard React hooks; PascalCase for React component names; kebab-case for route files.
- **File Structure:** Components in `src/components/`, pages/routes in `src/app/` (Next.js App Router format), database utilities in `src/lib/supabase.js`.
- **Quality Gates:** Code compiles without type errors, linter checks pass, drag-and-drop mechanics work smoothly, and save/load actions verify successfully.

## Key Principles
- Ship the simplest possible solution that solves the user story.
- Focus on distraction-free study layout. Keep UI components visually calm (white, gray, light neutral colors, clean sans-serif typography).
- Verify drag-and-drop and save functionality locally before updating MEMORY.md.
